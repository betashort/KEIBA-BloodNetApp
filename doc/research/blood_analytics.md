# 血統分析

## 血統分析で何を見るのか

主に以下を分析します。

| 項目         | 分析内容                 |
| ------------ | ------------------------ |
| 距離適性     | 短距離型か、中長距離型か |
| 馬場適性     | 芝・ダート・重馬場       |
| 成長力       | 早熟 / 晩成              |
| スピード能力 | 瞬発力・先行力           |
| スタミナ     | 持久力・底力             |
| 気性         | 折り合い・気難しさ       |
| 体質         | 故障傾向・丈夫さ         |
| コース適性   | 坂・小回り・直線長い等   |
| 配合相性     | ニックス・クロス効果     |

---

## 血統表の基本構造

競馬では通常「5代血統表」を見ます。

```text
          父
      ┌───┴───┐
    父父       父母
馬
    母父       母母
      └───┬───┘
          母
```

**特に重要**  

* 父
* 母父（BMS: Broodmare Sire）
* 3代目以内のクロス

---

## 父系分析

父系のポイント

* スピード
* 距離適性
* 成長力
* 産駒傾向

例：

* ディープインパクト

  * 瞬発力
  * 芝中距離
  * 切れ味

* ロードカナロア

  * スプリント
  * スピード
  * 早熟寄り

* キタサンブラック

  * 持続力
  * 中長距離
  * 成長力

---

## 母系分析（超重要）

実は競馬では「母系」が非常に重要です。

特に：

* 母父
* 牝系
* ファミリーライン（○号族）

を重視します。

### 母父の役割

母父は：

* 気性
* 柔らかさ
* スタミナ
* パワー

を補完するケースが多いです。

例：

* サンデー系 × 欧州母系
* キングマンボ系 × 米国スピード系

など。

---

### 号族（ファミリーライン）

以前質問されていた「10号族-a分岐」もここに関係します。

号族とは：

> 母系の祖先ライン分類

です。

例えば：

* 1号族 → 名牝系多数
* 8号族 → パワー型
* 10号族 → スピード型が多い

などの傾向があります。

近年は：

* 「どの号族が走るか」
  より、
* 「その分岐ラインが活発か」

を重視することが多いです。

---

## インブリード（クロス）

同じ祖先を血統表内に複数持つこと。

例：

```text
Northern Dancer 4×4
```

これは：

* 4代目に2本存在

という意味。

---

### クロスで期待される効果

| クロス対象         | 効果           |
| ------------------ | -------------- |
| Northern Dancer    | スピード       |
| Hail to Reason     | 気性・底力     |
| Mr. Prospector     | パワー・ダート |
| Roberto            | スタミナ       |
| サンデーサイレンス | 瞬発力         |

---

### ニックス（配合相性）

特定の系統同士が好相性になること。

例：

| 組み合わせ               | 傾向         |
| ------------------------ | ------------ |
| サンデー系 × Kingmambo系 | 日本芝王道   |
| Storm Cat × ディープ系   | スピード強化 |
| ロベルト系 × サンデー系  | 持続力       |

---

## 現代血統分析で重要な考え方

最近は単純な「父だけ分析」ではなく：

### 1. 系統バランス

* 日本型スピード
* 欧州型スタミナ
* 米国型パワー

の配合バランスを見る。

---

### 2. 主導遺伝

どの祖先の特徴が強く出るか。

例えば：

* 母系に強烈な欧州血統
* 父が日本スピード型

なら、
「重厚な持続力型」になる可能性。

---

### 3. 活力指数

クロス濃度や世代バランスを見る理論。

---

### 4. 血統勢力図

現在の日本競馬は：

* サンデー系
* キングマンボ系
* ロベルト系
* 欧州Sadler's Wells系

などの勢力図があります。

---

## 一口馬主向け分析視点

出資馬選びなら：

### 重要度高

* 母系の活力
* 兄弟成績
* 母の繁殖成績
* 種牡馬との相性
* 体型との一致

### 注意

「超良血」でも走らないケースは多いです。

理由：

* 配合バランス
* 気性
* 体質
* 運動能力

は血統だけでは決まらないため。
